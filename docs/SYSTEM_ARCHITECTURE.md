# Oceara System Architecture

## Project

Blockchain-Based Blue Carbon Registry & MRV System

## Objective

Oceara is intended to provide a digital workflow for registering blue-carbon projects, collecting MRV data, supporting remote-sensing analysis, validating project information, generating reports, and maintaining a blockchain-backed registry.

## Current Application

The current application is built using:

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Supabase
- Firebase
- Three.js / React Three Fiber
- Mapbox
- Google Maps
- Recharts
- jsPDF

## Existing Application Areas

- Landing page
- Authentication
- Landowner workflow
- Buyer workflow
- Admin workflow
- Reports
- Satellite analysis
- Wallet
- API routes for projects, profiles, uploads, authentication and audit logs

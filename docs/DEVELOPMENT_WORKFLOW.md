## Rules

1. Do not commit directly to main for normal feature work.
2. Use your own GitHub account.
3. Keep commits focused on actual work.
4. Do not commit secrets or credentials.
5. Pull the latest main before starting new work.
6. Test changes before opening a pull request.
7. Link the relevant GitHub Issue in the pull request.
